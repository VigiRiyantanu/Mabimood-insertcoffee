01 — Tentang Saya

Sedang dalam perjalanan belajar, siap berkarya

Saya percaya kode yang baik itu sederhana, mudah dibaca, dan menyelesaikan masalah yang nyata.

Perkenalan singkat

Saya Nurul Fitriani, seorang student yang sedang belajar membangun perangkat lunak. Ketertarikan saya pada dunia teknologi bermula sejak belajar membuat halaman web sederhana, ketika saya menyadari bahwa logika yang tertulis di dalam kode bisa menyelesaikan masalah yang nyata.

Saat ini saya berfokus memperdalam web development: menyusun antarmuka yang responsif, menulis JavaScript yang rapi, dan memahami cara kerja API serta database di baliknya.

Fokus & bidang yang saya pelajari

  • Frontend Web — HTML semantik, CSS modern (Flexbox, Grid, responsif), JavaScript (DOM, fetch, async/await).
  • Backend Dasar — REST API, validasi input, autentikasi dasar, dan operasi CRUD pada database.
  • DevOps & Tools — Git/GitHub untuk alur kerja kolaboratif, terminal Linux, dan kontainer dengan Docker.
  • Networking — memahami cara kerja HTTP, DNS, dan request-response di jaringan.

Tujuan & ketertarikan saya

Tujuan jangka pendek saya adalah menyelesaikan pembelajaran fundamental, membangun beberapa proyek nyata dari nol, lalu aktif berkontribusi pada proyek open source. Untuk jangka panjang, saya ingin berkembang menjadi developer yang tidak hanya bisa menulis kode, tetapi juga memahami mengapa sebuah solusi dipilih di atas solusi lain.
