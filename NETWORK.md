## ⚡ Cara Menjalankan Server di Masa Depan

Jika komputer di-restart atau server mati, Anda dapat menjalankannya kembali dengan sangat mudah:

1. **Cara Cepat (1-Klik):**
   - Cukup klik dua kali file [`start-server.bat`](file:///c:/Users/hiura/Documents/mbg/teamproject/start-server.bat) di folder project. Browser akan otomatis terbuka.
2. **Atau Lewat Terminal:**
   ```bash
   python server.py
   ```
