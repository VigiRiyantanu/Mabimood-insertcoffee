Pengaturan Cloud Firestore & Auth

Hubungkan dashboard ini dengan Cloud Firestore untuk sinkronisasi pesanan real-time antar perangkat dan kasir.

Kredensial Firebase Web App

Dapatkan nilai ini dari Firebase Console > Project Settings > General > Your Apps (Web App SDK).

Panduan Singkat Setup Firebase

  1. Buat Project di Firebase Console:

    Buka console.firebase.google.com dan buat project baru.

  2. Aktifkan Cloud Firestore:

    Buka menu Firestore Database > Create database > pilih mode Test mode (atau atur aturan izin baca/tulis berikut):

    rules_version = '2';
    service cloud.firestore {
      match /databases/{database}/documents {
        match /{document=**} {
          allow read, write: if true;
        }
      }
    }
  3. Aktifkan Firebase Authentication:

    Buka menu Authentication > Sign-in method > aktifkan provider Email/Password.

  4. Salin Config Web SDK:

    Buka Project Settings > Tambah Web App (</>) > salin nilai firebaseConfig dan simpan pada form di sebelah kiri.
