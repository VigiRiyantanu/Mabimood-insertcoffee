# ✨ Animated Portfolio Landing Page

![Project Presentation](public/foto.jpg)

A visually stunning and interactive portfolio landing page built with **React**, **Three.js**, and **Vite**. This project focuses on delivering immersive 3D graphics and smooth animations for a premium user experience.

---

## 🚀 Features

- **Immersive 3D Experience:** Uses `three.js` to render highly interactive WebGL elements directly in the browser.
- **Dynamic Shaders & Graphics:** Custom shader implementation for smooth transitions and visual effects.
- **Modern Tech Stack:** Built on top of **React 19** with **TypeScript** for robust state management and strict typing.
- **Lightning Fast Performance:** Uses **Vite** for instantaneous local development server and optimized production builds.

## 🛠️ Tech Stack

- **Framework:** React 19
- **3D Graphics:** Three.js & @designcodeio/threeui
- **Styling:** Vanilla CSS 
- **Language:** TypeScript
- **Bundler / Build Tool:** Vite

---

## 💻 Getting Started

### 1. Prerequisites
Make sure you have **Node.js** (v18 or newer recommended) installed on your machine.

### 2. Installation
Clone this repository and install the required dependencies:

```bash
git clone https://github.com/VigiRiyantanu/portofolio-landingpage-animated.git
cd portofolio-landingpage-animated
npm install
```

### 3. Running the Development Server
Start the local Vite development server:

```bash
npm run dev
```

Open `http://localhost:5173` in your browser to view the project.

### 4. Build for Production
To generate a production-ready bundle, run:

```bash
npm run build
```
The optimized files will be generated inside the `dist` folder.
