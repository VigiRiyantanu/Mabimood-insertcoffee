Tentang Cafe

We made a place to drink and play.

Insert Coffee started with a simple premise: coffee shops are good, arcade bars are good, and nobody had put the two together in a way that felt right. No theme park energy, no neon overload. Just a quiet corner to sit with a good drink and something to play.

We opened with a short menu of drinks we actually wanted to drink ourselves — properly pulled espresso, a few variations, and a signature or two. Everything is made to order. Nothing sits on a hot plate.

The arcade side is a curated set of classics. Not a hundred machines collecting dust, but ten that work well and never get old. Snake, Tetris, Breakout, Space Invaders, and a few others. They run right in the browser, so you can queue up a game from your phone while you wait for your coffee.

The Menu

Short and honest. Espresso is the base of everything. We pull it from a blend that works as well as a standalone shot as it does in milk. Iced drinks are made fresh — no concentrated syrups. The signature section is where we experiment, but only with things we'd order again.

The Arcade

Every game has one job: be worth playing for five minutes. We picked classics because they hold up — the controls are immediate, the rules are clear, and the skill ceiling is high enough that a good run always feels earned. High scores are saved locally to your browser.

Pengaturan Cloud Firestore & Auth

Hubungkan aplikasi dengan project Firebase Anda untuk sinkronisasi database cloud antar perangkat.

Kredensial Firebase Web App

Dapatkan nilai ini dari Firebase Console > Project Settings > General > Your Apps (Web App SDK).

Panduan Singkat Setup Firebase

  1. Buat Project di Firebase Console:

    Buka console.firebase.google.com dan buat project baru.

  2. Aktifkan Cloud Firestore:

    Buka menu Firestore Database > Create database > pilih mode Test mode (atau atur aturan baca/tulis).

    rules_version = '2';
    service cloud.firestore {
      match /databases/{database}/documents {
        match /{document=**} {
          allow read, write: if true;
        }
      }
    }
  3. Aktifkan Firebase Authentication:

    Buka menu Authentication > Sign-in method > aktifkan Email/Password.

  4. Salin Config Web:

    Buka Project Settings > Tambah Web App (</>) > salin objek firebaseConfig dan tempel pada form di samping.
